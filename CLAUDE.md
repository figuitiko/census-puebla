## Stack

- Next.js **16.3.8** (App Router), React **19.2.8**, TypeScript strict, Tailwind CSS **v4** (via `@tailwindcss/postcss`, no `tailwind.config`).
- Next 16 differs from older versions. Docs ship locally in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`). Read relevant guide before writing Next code.
- Path alias: `@/*` → repo root (not `src/`).
- ESLint uses `eslint-config-next` `core-web-vitals` + `typescript` presets.

## Architecture

Fresh `create-next-app` scaffold; only `app/` router exists (`layout.tsx`, `page.tsx`, `globals.css`). No API routes, data layer, or components dir yet.

- `app/layout.tsx` types props with the global `LayoutProps<"/">` helper (generated by Next typegen, no import needed). Loads Geist / Geist Mono via `next/font/google` as CSS vars `--font-geist-sans` / `--font-geist-mono`.
- Route types are generated into `.next/types` / `.next/dev/types` (included in `tsconfig.json`); run `pnpm dev` or `next typegen` if `LayoutProps`/`PageProps` are missing.
- `pnpm-workspace.yaml` only holds `ignoredBuiltDependencies` (`sharp`, `unrs-resolver`), not a real monorepo.

## Config (env vars)

- `MIN_PHOTOS`: confirmed photos required per located unit before a cedula can be submitted. Read server-side by `getMinPhotos()` (`lib/campaign-rules.ts`) on every call. **Unset or blank = 1** (testing default). Set `MIN_PHOTOS=10` for real data (the survey requires 10); `/admin/campaign` shows a warning while it is lower. A malformed value throws on purpose. `0` disables the gate. The old `Campaign.minPhotos` column is deprecated and unused.
- `NEXT_PUBLIC_BLOB_ACCESS`: `public` only for a public Blob store while testing; unset = `private` (production). Must match the store's mode. Restart `next dev` after changing it.
